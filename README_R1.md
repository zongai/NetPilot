# NetPilot R1 Release Add-on Task Pack

Independent release-stage add-on for completed NetPilot V5 (NP-145..NP-240).

Tasks: NP-241..NP-264, exactly 24 tasks.

Purpose: turn a functionally implemented V5 build into a Windows Release Candidate and, after final human approval, NetPilot 1.0 Final.

This ZIP is NOT a finished installer and does NOT claim NetPilot 1.0 is already built. The tasks must be executed against the real V5 source tree and verified on Windows.

Final acceptance must cover installation, first run, Core/IPC, subscription, proxy, rules, DNS, TUN where supported, connections/logs, security, stability, performance, upgrade/uninstall, and clean-machine operation.
